Block-Causal Bidirectional Attention Mechanics

Unlike standard autoregressive models with strict lower-triangular causal masks, DiffusionGemma uses a block-causal mask where tokens within the active 256-token canvas attend bidirectionally to each other while attending causally to previous committed blocks.

Intra-Canvas Attention: Fully Bidirectional (all 256 tokens attend to each other)
Inter-Block Attention: Strictly Causal (Canvas k can attend to Block 0...k-1)
KV Cache Chaining: Prefix Blocks stored as immutable KV tokens
