DiffusionGemma-Lite

A pure-PyTorch block-autoregressive language model. It reconstructs clean tokens from corrupted canvases during training and generates one canvas at a time through repeated denoising.

Overview

Attention is causal across canvases and bidirectional within each canvas. A learned time embedding conditions the backbone. This is not an ordinary next-token-only model and the sampler is not an ODE solver.

Open system diagram

Model

The configured backbone contains 24 DenoiseBlocks with 16 query heads, four KV heads and head width 64. CanvasTimeEmbedding maps 256 sinusoidal features through an MLP to width 1024. The time signal is added to token embeddings inside the backbone, not to corrupted token IDs.

Training feeds hidden states, tied embedding weights and clean targets into chunked cross-entropy. Sampling instead materializes logits and a vocabulary posterior. Optional self-conditioning re-embeds the model's posterior and adds it once.

Data

The shared preparation pipeline owns download, cleaning and packing. ShardWindows copies each within-shard window and converts it to int64. A fixed seeded permutation plus an offset determines the data order, not a new shuffle each epoch.

Integration caveat: packing can select uint16 for GPT-2's 50,257-token vocabulary, while this loader assumes uint32. No emitted manifest was verified here. Check the actual storage contract before training. The 160 × 50M shard figure is budget arithmetic, not a corpus inventory.

Training

Each canvas draws t uniformly from 1 through 16. Corruption uses cosine signal retention. With probability 0.5, a detached pre-pass supplies self-conditioning. At configured micro-batch 16, vocabulary chunks have width 4096.

The finite-loss gate precedes backward. Every two micro-steps, gradients are clipped and AdamW and its scheduler advance. Five consecutive nonfinite micro-batches restore the latest complete checkpoint, or abort if none exists. The loop has no held-out validation transition.

Checkpoints are direct writes of weights, optimizer and JSON metadata, not an atomic three-file transaction. Seeded step draws help reproducibility, but pending gradients and RNG state are not serialized. Skipped micro-batches complicate exact resume.

Canvas sampling

Each canvas starts from pure uniform noise. Newly committed positions receive sampled predictions. Previously committed positions are immutable and uncommitted positions redraw uniformly. The loop repeats until its step budget is reached or adaptive stopping succeeds, then re-encodes and appends the finalized canvas to the KV cache.

Sampler defaults use T=32 and temperature τ(k)=0.8−0.4k/T for k=0,…,T−1. The final iteration approaches but does not reach 0.4. Entropy averages all positions and batch members. Adaptive stopping requires strict H < threshold for two consecutive iterations.

Finalized-canvas re-encoding sees all prefix and canvas positions. The earlier toy 1000-step simulator was removed because it did not represent these configured semantics.
